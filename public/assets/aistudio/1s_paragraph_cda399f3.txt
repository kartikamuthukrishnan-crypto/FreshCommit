### TASK OBJECTIVE
Generate the mandatory first paragraph of a job description formatted strictly in HTML (<p>...</p>). 
This paragraph must be mathematically optimized for "Google for Jobs" algorithmic ranking, semantic keyword relevancy, and multi-tier geo-proximity search matching across US/North American locations.

---

### INSTRUCTION RULES FOR THE MODEL

1. OUTPUT FORMAT & HTML CONSTRAINTS:
   - Output ONLY the first paragraph enclosed inside `<p>...</p>` tags.
   - Do NOT include headings, bullet points, introductory chatter, or meta-comments.
   - Wrap high-intent search terms inside `<strong>...</strong>` tags.

2. MANDATORY KEYWORD & GEOGRAPHIC FORMULA:
   Sentence 1 (Company + Standard Title + Micro-to-Macro Location):
   - Pattern: "[Company Name] is hiring a/an <strong>[Standard Job Title]</strong> to join our [Department/Team] team based in <strong>[Neighborhood/District/Campus], [City], [State/Province Abbreviation or Name]</strong>."
   - Rule: Never use non-standard job titles (e.g., use "Software Engineer" or "Frontend Developer", not "Rockstar Developer" or "Code Wizard").

   Sentence 2 (Work Arrangement + Seniority Level + Experience Bracket):
   - Pattern: "This <strong>[Work Model: full-time on-site / hybrid / remote]</strong> position is open to <strong>[Seniority/Role Label, e.g., entry-level candidates / junior engineers / senior professionals]</strong> with <strong>[Experience Bracket, e.g., 0–1 year / 3+ years]</strong> of hands-on experience..."
   - Rule: Use standard US career terms (e.g., "entry-level", "junior", "mid-level", "senior", "recent college graduates").

   Sentence 3 (Tech Stack / Core Competencies + Metro Area / Regional Hub):
   - Pattern: "...focusing on <strong>[Core Skill 1]</strong>, <strong>[Core Skill 2]</strong>, and [Primary Focus Area / Tech Stack], serving clients and teams across the greater <strong>[Metro Area / Regional Business Hub, e.g., Greater Boston Area / Silicon Valley / Dallas-Fort Worth Metroplex]</strong>."

3. GEOGRAPHIC FALLBACK RULES:
   - If {{neighborhood}} is absent, default to: "[City], [State/Province]" (e.g., "Austin, TX").
   - If {{metro_or_region}} is absent, omit the secondary regional clause and close cleanly at the tech stack.
   - For Remote roles, format location as: "<strong>Remote ([City], [State] Hub)</strong>" or specify regional boundaries (e.g., "<strong>Remote (US-Based)</strong>").

---

### DYNAMIC VARIABLES MAPPING
Ensure your backend payload supplies the following fields:
- {{company_name}}
